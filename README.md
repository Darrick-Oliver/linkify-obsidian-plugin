# Linkify Plugin

Enhances link experience with two plugins:

1. Link edit interceptor

    - Lets you choose between editing and following a clicked link
    - Edit menu inspired by Slack's link edit

1. Selection paste

    - Converts pasted links over a selection of text into a markdown link

## Using this Plugin

Since I'm too lazy to submit this plugin to Obsidian, you can install this by:

1. Install git and node
1. Going to your plugins folder (e.g. `/Obsidian/ObsidianVault/.obsidian/plugins`) and running `git clone https://github.com/Darrick-Oliver/linkify-obsidian-plugin.git`
1. Run `npm run build`
